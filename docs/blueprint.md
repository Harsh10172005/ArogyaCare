# **App Name**: ArogyaCare

## Core Features:

- Homepage Dashboard: Display a landing page with quick links to medicine, hospitals, health camps, and an AI doctor.
- 24/7 Medicine Access: Allow users to browse and 'purchase' (without payment processing) medicines categorized by type.
- Emergency Hospital Locator: Display a list of nearby hospitals based on the user's location.
- Free HealthCamp Listings: Show upcoming healthcare camps with details and registration links.
- AI Health Assistant: Provide an AI chatbot interface that answers general health questions using an LLM tool. AI provides health guidance; no medical prescriptions will be generated.
- Wellness Information Display: Offer an interface to display the additional sections (Nutrition, Supplements, Healthy Habits, Testimonials) mentioned in the prompt. 

## Style Guidelines:

- Primary color: Deep purple (#6750A4) for a sense of trust and wellness.
- Background color: Very light purple (#F2EEFA) for a calming backdrop.
- Accent color: Teal (#50A483) to highlight important actions and sections.
- Body and headline font: 'PT Sans' (sans-serif) to give a modern, slightly warm, readable feel throughout the site.
- Use health-related icons to enhance UX, clearly representing each service or section.
- Employ a card-based layout with rounded corners and soft shadows.
- Add subtle transitions when loading data and light hover effects.
